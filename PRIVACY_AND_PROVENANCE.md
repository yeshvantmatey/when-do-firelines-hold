# Publication-copy privacy and provenance

Original local research files were not edited. Public copies replace workstation-specific paths with project-relative paths or explicit placeholders. Historical Python project roots use FIRELINE_PROJECT_ROOT where applicable. All released notebooks have empty execution outputs, cleared execution counts and no saved widget state. The notebook transformations were syntax-checked. Source hashes describe original artifacts; current release hashes describe the publication copies.

No recognized API-token, password, embedded-credential URL or private-key pattern was found by the preparation scans. Public scientific coordinates, fire identifiers, author contact information and upstream agency/template contact information were intentionally retained. The original NIFC metadata ZIP contains one standard source-author Metavist stylesheet path; it is preserved as upstream published provenance and is not the researcher's workstation path.

Scans inspected text, parsed notebook sources/metadata, nested ZIP text, PDF metadata/extractable text and Parquet string fields. Pattern scans cannot establish absence of every possible secret; text extraction from dense historical PDF graphics is incomplete. No matched credential values are included in reports.

Historical validation/source manifests refer to the earlier files and directory layout. Use release_manifest.json and checksums.sha256 for the current package. The dataset also provides validation/release_file_manifest.json for the portable verification script. Scientific observations, predictor values, saved predictions and numeric result tables were retained; ancillary local provenance strings were normalized.
