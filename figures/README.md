# Added figure sources and plotted inputs

Read `../docs/FIGURE_REPRODUCTION.md` for commands, input definitions, attribution, and verification. Start with `regenerate_figures.ipynb` or one of the portable `reproduce_*.py` scripts.

- `inputs/`: saved plotted data, original-CRS geometry extracts, and Census boundaries.
- `original_sources/`: historical sources with notebook outputs cleared.
- `reference_outputs/`: unchanged reference PDFs and PNGs.
- `source_manifest.json`: source and release hashes with documented transformations.
- `validation.json`: successful redraw checks and tested dependency versions.

The historical editorial builder is explicitly separated from the current pooled forward-year and condition-group outputs. No files are uploaded by these scripts.
