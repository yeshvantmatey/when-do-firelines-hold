# Historical source audits

The inventories, saved fingerprints and earlier validation records in this directory describe the original research workspace and the previous packaging stages. Original paths are stored as project-relative provenance or public placeholders. They are not instructions to read those paths from a GitHub checkout.

The current repository adds configurable project roots, cleared execution state and current README/links. Historical source-cell fingerprints therefore identify their original sources; they should not be interpreted as hashes of every current publication copy. The current release manifest supplies current hashes. The numerical analysis and fixed prediction inputs remain unchanged.
